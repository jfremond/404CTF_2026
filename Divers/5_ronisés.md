# 5 Ronisés

## Objective
For this challenge we have to guess the "super secret number" generated by the program.


## Resolution
The vulnerability resides in `int(time())`. Since we know this value only changes
once per second, we can predict it.

All that's left to do is write a program that generates the secret number so we can
test it against the original program.

Due to network issues, I had to generate 6 values and solve the challenge with
the sixth value. If you don't have this issues you may reduce the `seconds`' range.
```python
from time import time
from random import seed, randint
from hashlib import sha256
from functools import reduce

# Base code from challenge.py
def matmul(A, B):
    Bt = list(zip(*B))
    return [[sum(a * b for a, b in zip(row, col)) for col in Bt] for row in A]


def genere_nombre_super_secret(n, s):
    seed(s)
    A = [[randint(0, pow(2, 64)) for _ in range(n)] for _ in range(n)]

    for i in range(pow(2, 10)):
        A = matmul(A, A)
        A = [[y % pow(2, 64) for y in x] for x in A]

    base = reduce(lambda x, y: x ^ y, [reduce(lambda x, y: x ^ y, row) for row in A])
    hashed = sha256(hex(base).encode()).hexdigest()
    return int(hashed, 16)


# New code to generate values
def generate_values():
    t = int(time())
    seconds = list(range(t - 5, t + 1)) # the last 6 seconds to t
    results = []
    for second in seconds:
        val = genere_nombre_super_secret(8, second)
        results.append(val)
    return results


def main():
    results = generate_values()
    for val in results:
        print(val)


if __name__ == "__main__":
    main()
```
