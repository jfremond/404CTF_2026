# Canular Savant (1/3)

## Objective
For this challenge we have to fined a Parisian roundabout surrounded by several
fountains.

Expected flag format: `404CTF{carrefour-etoile_du_porte-avion-charles-de-gaulle}`

## Resolution

We search on the internet for a Parisian roundabout surrounded by several fountains.
We easily find that it is the
[`Rond-point des Champs Elysées`](https://fr.wikipedia.org/wiki/Rond-point_des_Champs-%C3%89lys%C3%A9es-Marcel-Dassault).
We need the full name of the roundabout to complete this challenge,
the full name being `Rond-point des Champs-Élysées-Marcel-Dassault`.

The flag for this challenge is `404CTF{rond-point_des_champs-elysees-marcel-dassault}`.
